# Community code of conduct

Be respectful, constructive, and welcoming. Discuss code and ideas without
personal attacks. Harassment, discrimination, threats, doxxing, and publishing
someone else's private information are not acceptable.

This applies to project issues, pull requests, discussions, and other spaces
representing this project. Follow maintainers' moderation requests. Maintainers
may edit or remove harmful content, close discussions, or restrict participation.

Report concerns privately to the repository owner through their GitHub profile:
https://github.com/MagiqueDeveloper. If a private contact route is unavailable,
use GitHub's report-abuse tools; do not post sensitive details in a public issue.
Reports will be handled with discretion to the extent the available tools permit.
