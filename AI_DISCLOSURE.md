# AI use disclosure

AI tools have assisted with this application's design, implementation, debugging,
tests, and documentation. This includes the Treasure Hunters update. AI tools are
tools used in the development process, not project contributors or maintainers.

AI-generated output can contain mistakes. Passing automated checks does not prove
that code is secure, accessible, or that game data is accurate. The maintainer is
responsible for deciding which changes to accept and publish. Contributors should
review and understand any AI-assisted submission and disclose substantial AI use
in its pull request.

The application does not call an AI service, send collection progress to an AI
provider, or require an AI account. Collection progress stays in your browser and is not sent to this project’s
servers. Fortnite artwork is sourced from the references
in THIRD_PARTY_NOTICES.md; it is not presented as AI-generated artwork.
